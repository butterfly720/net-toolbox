输入每种 VLAN 需要容纳的主机数，自动算出整套方案：VLAN ID、网段、掩码、网关、DHCP 地址池，并可导出 Markdown 表格与 Cisco 配置片段。

该模式下 VLAN 21 会自动对应 192.168.21.0/24，设备与网段一一对应，便于排障。

这套查询背后的链路

  1. 浏览器向你输入的域名发 HTTPS 请求，先要把它解析成 IP
  2. 本机 → 本地 DNS 缓存 → 路由器 → 运营商 DNS，逐级询问
  3. 若都没有，则向根域名服务器发起迭代查询，逐级下沉到顶级域（.com）与权威 DNS
  4. 权威服务器返回记录，各级缓存并按 TTL 保存

上表里的 TTL 就是这条记录还能被缓存多久（单位：秒）。
